CASTLE OF MAGIC (Gameloft, 2008) - PC VERSION
=============================================

HOW TO PLAY
  1. Extract this whole folder anywhere (Desktop, Documents, ...). Keep the folders together.
  2. Double-click CastleOfMagic.exe.
  3. The PC SETTINGS screen opens first. Pick your options and choose PLAY.
     Press F1 during the game to open the settings again.

No emulator to set up and no Java to install. Everything the game needs is in this folder.

GAME VERSIONS (choose in the settings screen)
  HD Edition      352x416. Side-scrolling levels. Runs at 193 FPS by default
                  (also 96 FPS, 64 FPS for slower PCs, or the original 12 FPS).
  Full Adventure  240x320. Castle hub world plus levels.
                  Runs at its original 16 FPS game speed for now.
  Each version keeps its own save files (in the "saves" folder).

HIGH FRAME RATE
  The original game draws 12-16 pictures per second. In the HD Edition this PC version
  patches the game's timing so it draws up to 193 per second. Walking speed, jump height,
  timers and text speed were measured against the original and stay the same (within about 2%).
  If anything ever feels off, set "Frame rate" to the original value.

CONTROLS
  Move .................... Arrow keys or W A S D        (controller: D-pad / left stick)
  OK / action (phone 5) ... Enter, Space or Z            (controller: A)
  Menu / pause ............ Esc or Q                     (controller: Start)
  Back / skip ............. Backspace or X               (controller: B)
  Phone keys .............. 0-9 on the number row or numpad, numpad * and /
  PC settings ............. F1                           (controller: View/Back)
  Fullscreen .............. F11 or Alt+Enter
  FPS counter ............. F3
  Screenshot .............. F12 (saved in the "screenshots" folder)
  Xbox-compatible controllers work through XInput.

IF SOMETHING GOES WRONG
  - "Windows protected your PC": click "More info" then "Run anyway". The launcher is not
    signed, which is normal for home-made programs.
  - The game writes a log to logs\last-run.log.
  - Delete settings.properties to reset all settings.
