CASTLE OF MAGIC (Gameloft, 2008) - PC VERSION
=============================================

HOW TO PLAY
  1. Extract this whole folder anywhere (Desktop, Documents, ...). Keep the folders together.
  2. Double-click CastleOfMagic.exe.
  3. The PC SETTINGS screen opens first. Pick your options and choose PLAY.
     Press F1 during the game to open the settings again.

No emulator to set up and no Java to install. Everything the game needs is in this folder.

GAME VERSIONS (choose in the settings screen)
  Normal  240x320. Castle hub world plus levels. Supports multiplayer.
  HD      352x416. Side-scrolling levels only. Single player.
  Both are the original 2008 game files, unmodified. They run at their original speed.
  Each version keeps its own save files (in the "saves" folder).

MULTIPLAYER (Normal version, two PCs, over the internet)
  Each of you plays your own game. You see your friend as the YELLOW hero, with their
  name above, whenever you are in the same place (castle hall, same castle room, same level).
  A bar at the top always shows where your friend is.

  First time on each PC:
    Settings screen > Multiplayer > Server key: select the row and press Ctrl+V to paste
    the ACCESS_KEY from Render. Type your name.

  Host (you):
    1. Type a Room key (a secret word, 4+ letters).
    2. Choose "Create game". A 6-letter Room code appears.
    3. Tell your friend the Room code and the Room key. Then press PLAY.
  Friend:
    1. Type the same Room key and the Room code.
    2. Choose "Join game" BEFORE pressing PLAY. The host's progress is copied over, so you
       both have the same levels unlocked. (Your own old save is kept in saves\adventure\rms-own-backup-...)
    3. Press PLAY.

  The free Render server sleeps when nobody uses it. The first Create/Join can take up to
  a minute while it wakes up.
  The other hero is a "ghost": you see them run and jump, but each of you has your own
  enemies, bosses and progress.

CONTROLS
  Move .................... Arrow keys or W A S D        (controller: D-pad / left stick)
  OK / action (phone 5) ... Enter, Space or Z            (controller: A)
  Menu / pause ............ Esc or Q                     (controller: Start)
  Back / skip ............. Backspace or X               (controller: B)
  Phone keys .............. 0-9 on the number row or numpad, numpad * and /
  PC settings ............. F1                           (controller: View/Back)
  Fullscreen .............. F11 or Alt+Enter
  FPS counter ............. F3
  Screenshot .............. F12 (saved in the "screenshots" folder)
  Xbox-compatible controllers work through XInput.

IF SOMETHING GOES WRONG
  - "Windows protected your PC": click "More info" then "Run anyway". The launcher is not
    signed, which is normal for home-made programs.
  - The game writes a log to logs\last-run.log.
  - Delete settings.properties to reset all settings.
